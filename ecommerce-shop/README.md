# 🛒 ร้านของเรา — เว็บขายของสำหรับฝึก

เว็บขายของง่าย ๆ ทำจาก **HTML + CSS (Tailwind) + JavaScript** ไม่ต้องติดตั้งอะไร
เราจะใช้เว็บนี้ฝึกเป็น Dev — เข้าใจปัญหา แล้วใช้ **AI (GitHub Copilot)** ช่วยแก้โค้ด

---

## 🚀 เริ่มยังไง (ใน GitHub Codespaces)

1. กด **Fork** repo นี้ (ก็อปมาเป็นของเรา)
2. กดปุ่มเขียว **Code** → แท็บ **Codespaces** → **Create codespace**
3. รอสักครู่ เว็บจะเด้งขึ้นมาเอง (พอร์ต 5500)
   - ถ้าไม่เด้ง ให้ลง extension **Live Server** (เปิดเซิร์ฟเวอร์ในเครื่อง + รีเฟรชหน้าเว็บอัตโนมัติทุกครั้งที่แก้โค้ด รองรับทั้งหน้าแบบ static และ dynamic): แท็บ **Extensions** (ไอคอนสี่เหลี่ยมด้านซ้าย) → ค้นหา "Live Server" → กด **Install** → คลิกขวาไฟล์ `index.html` → เลือก **Open with Live Server**
   - หรือถ้าไม่อยากลง extension ใช้ Terminal พิมพ์: `python3 -m http.server 5500` แล้วกดที่แท็บ **PORTS** → เปิดพอร์ต 5500

---

## 📂 ไฟล์มีอะไรบ้าง

| ไฟล์ | คืออะไร |
|------|---------|
| `index.html` | **โครงหน้าเว็บ** — มีอะไรอยู่บนหน้าบ้าง (HTML) |
| `main.js` | **สมองของเว็บ** — โหลดสินค้า, ตะกร้า (JavaScript) |
| `products.json` | **ข้อมูลสินค้า** — ชื่อ, ราคา (เหมือนข้อมูลจากหลังบ้าน) |

> 💡 การจัดสไตล์ (สี ขนาด ระยะ) ใช้ **Tailwind** เขียนเป็น class อยู่ใน `index.html` เช่น
> `text-orange-600` = ตัวอักษรสีส้ม, `text-center` = จัดกึ่งกลาง

## 📝 โจทย์ 6 ข้อ (ทำทีละข้อ ง่าย → ยาก)

แต่ละข้อทำตามนี้: **เข้าใจโจทย์ → หาจุดที่ต้องแก้ → ให้ AI ช่วย → เช็คผล**
> ⚠️ ให้ **อ่านโค้ดที่ AI แก้ก่อนกดรับ (Keep)** ทุกครั้ง จะได้เข้าใจว่ามันทำอะไร

### ข้อ 1 — แก้คำ ✏️  *(ง่าย)*
เปลี่ยนชื่อร้าน + ข้อความต้อนรับ + ข้อความบนปุ่ม ให้เป็นของเรา
- 📍 จุดแก้: `index.html` หา 👉 `โจทย์ 1`
- 🤖 ตัวอย่างสั่ง AI: *"เปลี่ยนชื่อร้านเป็น ... และข้อความต้อนรับเป็น ..."*

### ข้อ 2 — แต่งการ์ดด้วย CSS ดิบ 🎨  *(ง่าย · CSS)*
การ์ด "ลดพิเศษวันนี้!" ยังโล่ง ๆ ไม่มีสไตล์เลย — แต่งให้สวยด้วย **CSS ธรรมดา** (ยังไม่ใช้ Tailwind)
- 📍 จุดแก้: `index.html` หา 👉 `โจทย์ 2` (คลาส `.promo-card` ในส่วน `<style>`)
- 🤖 ตัวอย่างสั่ง AI: *"แต่ง .promo-card ให้มีพื้นหลังสี มุมโค้ง มีระยะขอบใน"*
- 💡 สังเกตความต่าง: ข้อนี้ต้องสลับไปเขียนใน `<style>` แยกจาก HTML — ข้อถัดไปจะเห็นว่า Tailwind ทำแบบนี้ไม่ต้อง

### ข้อ 3 — แก้สไตล์ด้วย Tailwind 🎨  *(ง่าย)*
- ทำหัวข้อ "สินค้าทั้งหมด" ให้อยู่ **กึ่งกลาง**
- ทำ **ราคา** ให้เด่นขึ้น (เช่น สีส้ม ตัวหนา)
- 📍 จุดแก้: `index.html` และ `main.js` หา 👉 `โจทย์ 3`
- 🤖 ตัวอย่างสั่ง AI: *"จัดหัวข้อสินค้าทั้งหมดให้อยู่กึ่งกลาง และทำให้ราคาเป็นสีส้มตัวหนา"*
- 💡 เทียบกับข้อ 2: ข้อนี้แก้ style ติดกับ element เลย ไม่ต้องสลับไฟล์ — นี่คือข้อดีของ Tailwind

### ข้อ 4 — สร้างการ์ดสินค้า 🧱  *(กลาง · Tailwind)*
เพิ่มการ์ด "สินค้าแนะนำ" ใบที่ 3 (ก็อปโครงจากการ์ดที่มีอยู่)
- 📍 จุดแก้: `index.html` หา 👉 `โจทย์ 4`
- 🤖 ตัวอย่างสั่ง AI: *"เพิ่มการ์ดสินค้าแนะนำอีก 1 ใบ ชื่อ ... ราคา ... อีโมจิ ..."*

### ข้อ 5 — ทำปุ่ม "หยิบใส่ตะกร้า" ให้ทำงาน 🛒  *(ท้าทาย · JavaScript)*
ตอนนี้กดปุ่มแล้วยังไม่มีอะไรเกิดขึ้น — ทำให้มันเพิ่มสินค้าเข้าตะกร้าจริง ๆ
- 📍 จุดแก้: `main.js` หา 👉 `โจทย์ 5` (ฟังก์ชัน `addToCart`)
- 🤖 ตัวอย่างสั่ง AI: *"ทำให้ฟังก์ชัน addToCart หาสินค้าจาก id เพิ่มเข้า cart แล้วอัปเดตตัวเลขตะกร้าและรายการในตะกร้า"*
- ✅ เช็คผล: กดปุ่ม → ตัวเลขบน 🛒 เพิ่มขึ้น → กด 🛒 เห็นสินค้าในตะกร้า

### ข้อ 6 — โชว์ยอดรวมราคาตะกร้า 🔢  *(ท้าทาย · JavaScript)*
ตัวเลข "รวมทั้งหมด" ท้ายแผงตะกร้าค้างที่ ฿0 เสมอ — คิดยอดรวมให้ตรงจริง
- 📍 จุดแก้: `main.js` หา 👉 `โจทย์ 6` (ฟังก์ชัน `renderCart`)
- 🤖 ตัวอย่างสั่ง AI: *"อัปเดต #cart-total ให้โชว์ยอดรวมราคาสินค้าทั้งหมดในตะกร้า"*
- ✅ เช็คผล: หยิบสินค้าหลายชิ้น → ตัวเลขรวมบวกตามราคาจริง

---
