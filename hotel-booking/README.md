# 🏨 จองที่พัก — เว็บโรงแรมสำหรับฝึก (Hands-on)

เว็บจองที่พักง่าย ๆ ทำจาก **HTML + CSS (Tailwind) + JavaScript**
รอบนี้เราจะลองทำเองแบบที่ฝึกมาในช่วง Skill Development

---

## 🚀 เริ่มยังไง (ใน GitHub Codespaces)

1. กด **Fork** repo นี้
2. กดปุ่มเขียว **Code** → แท็บ **Codespaces** → **Create codespace**
3. ให้ลง extension **Live Server** (เปิดเซิร์ฟเวอร์ในเครื่อง + รีเฟรชหน้าเว็บอัตโนมัติทุกครั้งที่แก้โค้ด รองรับทั้งหน้าแบบ static และ dynamic): แท็บ **Extensions** (ไอคอนสี่เหลี่ยมด้านซ้าย) → ค้นหา "Live Server" → กด **Install** → คลิกขวาไฟล์ `index.html` → เลือก **Open with Live Server**

---

## 📂 ไฟล์มีอะไรบ้าง

| ไฟล์ | คืออะไร |
|------|---------|
| `index.html` | หน้าแรก — เมนู, แถบกรอง, ที่วางการ์ดโรงแรม |
| `about.html` | หน้า "เกี่ยวกับเรา" (ยังว่าง รอเติม) |
| `main.js` | โหลดโรงแรมจาก json, สร้างการ์ด, กรองตามเมือง |
| `hotels.json` | ข้อมูลโรงแรม — ชื่อ, เมือง, ราคา, ดาว |

## 📝 โจทย์ 6 ข้อ (ทำทีละข้อ ง่าย → ยาก)

แต่ละข้อทำตามนี้: **เข้าใจโจทย์ → หาจุดที่ต้องแก้ → ให้ AI ช่วย → เช็คผล**
> ⚠️ ให้ **อ่านโค้ดที่ AI แก้ก่อนกดรับ** ทุกครั้ง จะได้เข้าใจว่ามันทำอะไร

### ข้อ 1 — แก้คำ ✏️  *(ง่าย)*
เปลี่ยนข้อความต้อนรับ + คำโปรยใน HERO ให้เป็นของเรา (`index.html`)

### ข้อ 2 — แต่งการ์ด "ทำไมเลือกเรา" ด้วย Tailwind 🎨
การ์ดยังโล่ง ๆ ไม่มีสไตล์เลย — แต่งให้สวยด้วย Tailwind (`index.html`)

### ข้อ 3 — สร้างหน้า "เกี่ยวกับเรา" 📄
เติมเนื้อหาหน้า `about.html` ให้สมบูรณ์และสวยงาม ใช้ Tailwind

### ข้อ 4 — เพิ่มการ์ดโรงแรม 🧱
เพิ่มโรงแรมใหม่ 1 แห่งเข้าเว็บ (`hotels.json`)

### ข้อ 5 — ทำแถบกรองให้ทำงาน (filter) 🎚️
ตอนนี้กดปุ่มเมือง (กรุงเทพ / เชียงใหม่ / ภูเก็ต) แล้วยังไม่กรอง — ทำให้มันกรองได้ (`main.js` → `filterHotels`)

### ข้อ 6 — โชว์จำนวนผลลัพธ์ 🔢
ตัวเลข "พบ ... ที่พัก" ค้างที่ 0 เสมอ — อัปเดตให้ตรงกับที่กำลังแสดงอยู่ (`main.js` → `renderHotels`)

---
