# 🏨 จองที่พัก — เว็บโรงแรมสำหรับฝึก (Hands-on)

เว็บจองที่พักง่าย ๆ ทำจาก **HTML + CSS (Tailwind) + JavaScript**
รอบนี้เราจะลองทำเองแบบที่ฝึกมาในช่วง Skill Development

---

## 🚀 เริ่มยังไง (ใน GitHub Codespaces)

1. กด **Fork** repo นี้
2. กดปุ่มเขียว **Code** → แท็บ **Codespaces** → **Create codespace**
3. ให้ลง extension **Live Server** (เปิดเซิร์ฟเวอร์ในเครื่อง + รีเฟรชหน้าเว็บอัตโนมัติทุกครั้งที่แก้โค้ด รองรับทั้งหน้าแบบ static และ dynamic): แท็บ **Extensions** (ไอคอนสี่เหลี่ยมด้านซ้าย) → ค้นหา "Live Server" → กด **Install** → คลิกขวาไฟล์ `index.html` → เลือก **Open with Live Server**

---

## 📂 ไฟล์มีอะไรบ้าง

| ไฟล์ | คืออะไร |
|------|---------|
| `index.html` | หน้าแรก — เมนู, แถบกรอง, ที่วางการ์ดโรงแรม |
| `about.html` | หน้า "เกี่ยวกับเรา" (ยังว่าง รอเติม) |
| `main.js` | โหลดโรงแรมจาก json, สร้างการ์ด, กรองตามเมือง |
| `hotels.json` | ข้อมูลโรงแรม — ชื่อ, เมือง, ราคา, ดาว |

## 📝 โจทย์ 6 ข้อ (ทำทีละข้อ ง่าย → ยาก)

แต่ละข้อทำตามนี้: **เข้าใจโจทย์ → หาจุดที่ต้องแก้ → ให้ AI ช่วย → เช็คผล**
> ⚠️ ให้ **อ่านโค้ดที่ AI แก้ก่อนกดรับ** ทุกครั้ง จะได้เข้าใจว่ามันทำอะไร

### ข้อ 1 — แก้คำ ✏️  *(ง่าย)*
เปลี่ยนข้อความต้อนรับ + คำโปรยใน HERO ให้เป็นของเรา
- 📍 จุดแก้: `index.html` หา 👉 `โจทย์ 1`
- 🤖 ตัวอย่างสั่ง AI: *"เปลี่ยนข้อความต้อนรับเป็น ... และคำโปรยเป็น ..."*

### ข้อ 2 — แต่งการ์ดด้วย CSS ดิบ 🎨
การ์ด "ทำไมเลือกเรา" ยังโล่ง ๆ ไม่มีสไตล์เลย — แต่งให้สวยด้วย **CSS ธรรมดา** (ยังไม่ใช้ Tailwind)
- 📍 จุดแก้: `index.html` หา 👉 `โจทย์ 2` (คลาส `.why-us-card` ในส่วน `<style>`)
- 🤖 ตัวอย่างสั่ง AI: *"แต่ง .why-us-card ให้มีพื้นหลังสี มุมโค้ง มีระยะขอบใน"*
- 💡 สังเกตความต่าง: ข้อนี้ต้องสลับไปเขียนใน `<style>` แยกจาก HTML — ข้อถัดไปจะเห็นว่า Tailwind ทำแบบนี้ไม่ต้อง

### ข้อ 3 — สร้างหน้า "เกี่ยวกับเรา" 📄
เติมเนื้อหาหน้า `about.html` ให้สมบูรณ์และสวยงาม ใช้ Tailwind (เขียน class ติดกับ element เลย)
- 📍 จุดแก้: `about.html` หา 👉 `โจทย์ 3`
- 🤖 ตัวอย่างสั่ง AI: *"เติมเนื้อหาหน้าเกี่ยวกับเรา เล่าว่าเว็บนี้บริการอะไร จัดหน้าให้สวยด้วย Tailwind"*
- ✅ เช็คผล: กดเมนู "เกี่ยวกับเรา" แล้วเห็นเนื้อหา

### ข้อ 4 — เพิ่มการ์ดโรงแรม 🧱
เพิ่มโรงแรมใหม่ 1 แห่งเข้าเว็บ
- 📍 จุดแก้: `hotels.json` (เพิ่มข้อมูลอีก 1 ก้อน) — การ์ดจะโผล่มาเอง (สไตล์ Tailwind จากระบบที่มีอยู่แล้ว)
- 🤖 ตัวอย่างสั่ง AI: *"เพิ่มโรงแรมใน hotels.json ชื่อ ... เมือง ... ราคา ... ดาว ..."*

### ข้อ 5 — ทำแถบกรองให้ทำงาน (filter) 🎚️
ตอนนี้กดปุ่มเมือง (กรุงเทพ / เชียงใหม่ / ภูเก็ต) แล้วยังไม่กรอง — ทำให้มันกรองได้
- 📍 จุดแก้: `main.js` หา 👉 `โจทย์ 5` (ฟังก์ชัน `filterHotels`)
- 🤖 ตัวอย่างสั่ง AI: *"ทำให้ filterHotels กรองโรงแรมตามเมือง ถ้าเลือกทั้งหมดให้แสดงทุกอัน"*
- ✅ เช็คผล: กด "ภูเก็ต" → เหลือเฉพาะโรงแรมภูเก็ต, กด "ทั้งหมด" → กลับมาครบ

### ข้อ 6 — โชว์จำนวนผลลัพธ์ 🔢
ตัวเลข "พบ ... ที่พัก" ใต้หัวข้อ "ที่พักแนะนำ" ค้างที่ 0 เสมอ — อัปเดตให้ตรงกับที่กำลังแสดงอยู่
- 📍 จุดแก้: `main.js` หา 👉 `โจทย์ 6` (ฟังก์ชัน `renderHotels`)
- 🤖 ตัวอย่างสั่ง AI: *"อัปเดต #result-count ให้โชว์ 'พบ N ที่พัก' ตามจำนวนโรงแรมที่กำลังแสดง"*
- ✅ เช็คผล: กด "ภูเก็ต" → ตัวเลขเปลี่ยนเป็นจำนวนโรงแรมภูเก็ตจริง ๆ
